% Interelectrode capacitances (tube-capacitance): the set-up a person would wire, semantically the deck's.
%   VG1g g1g 0 DC <vg> AC 1, VAg ag 0 250, VKg kg 0 0, XCg …   copy A: the grid driven, every other electrode at AC ground through its ammeter
%   VAa aa 0 DC 250 AC 1, …, XCa …                              copy B: the anode driven
%   (pentode) VG2s g2s 0 DC 250 AC 1, …, XCs …                  copy C: the screen driven
%   .ac at 1 MHz; C between two electrodes = Im(i) / (2 pi f) of the current into the undriven one

\definitions{0,-0.1}{%
  $V_a = 250$ V, $V_{g2} = 250$ V, $V_{g1}$ at the model's cut-off (the tube cold, as the sheets measure it), and again at $I_a = I_0/4$ (hot);\quad $v = 1$ V of AC at $f = 1$ MHz\\[2pt]
