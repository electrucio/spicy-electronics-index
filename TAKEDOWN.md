# Takedown policy

Spicy Electronics Index hosts **links and facts**, not third-party documents. Schematics, magazine scans, books and
datasheets are referenced by public URL. Manufacturer SPICE models are hosted only when their licence
permits redistribution; otherwise the project records where the model can be obtained.

If you are the rights holder or the operator of a linked site and want an entry removed or corrected:

1. Open an issue using the "Takedown request" form, or contact the maintainer through the GitHub profile
   of the repository owner.
2. Say which URLs, source or files are concerned. No justification is required for removing links to your
   own site.

What happens next:

- Individual documents are added to `data/schematics/withdrawn.csv`; a whole site has its registry entry
  set to `excluded`. Hosted files, if any, are deleted.
- The change is published with the next site deployment. The target is seven days from the request.
- The removal is listed below.
